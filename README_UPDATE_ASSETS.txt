ENDOG NIBO - UPDATE ASSETS

Paket ini berbasis Endog_Nibo_FIX_V2 yang sudah diperbaiki untuk crash toko/collision.

Aset baru di assets/items/:
- egg_shield.png     -> pelindung 1 kesalahan
- magnet.png         -> power-up magnet
- slow_time.png      -> power-up memperlambat telur
- coin_boost.png     -> bonus koin x2

Catatan:
Aset sudah dimasukkan ke ZIP, tetapi fitur gameplay baru belum diaktifkan oleh file main.py.
Kita bisa lanjut mengintegrasikan item satu per satu setelah asetnya siap.

Cara pakai di Pydroid 3:
1. Extract ZIP.
2. Buka folder Endog_Nibo.
3. Jalankan main.py.
4. Jangan hapus data.json jika ingin mempertahankan progres.
